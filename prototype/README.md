# TraceIQ Nexus — Prototype Application
See the root `README.md` for full Windows setup, test execution, and architecture guides.

To run directly from this directory:
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```
Open `http://127.0.0.1:5000` in your web browser.
